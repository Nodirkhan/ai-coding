# Trackly context

## Glossary

- **Work item**: the user-facing name (UI labels, headings, messages) for what the code, API routes (`/api/issues`), service functions and database table call an **issue**. Same concept; only the UI says "work item".
- **Board**: the `/boards` page. One column per status (To do, In progress, Done); cards are dragged between columns to change status. Order within a column is not stored: cards sort by priority, then newest first.
- **Work Items**: the `/work-items` page, a sortable, filterable table of all work items.
